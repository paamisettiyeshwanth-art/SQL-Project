# Student Profile Management System

## Description

This is a SQL Server project used to manage student profile information.

The project stores student details, courses, marks, CGPA, and technical skills.

## Features

- Student profile management
- Course management
- Student marks management
- Technical skills management
- CGPA analysis
- Department-wise student count
- Student search and filtering
- Student performance analysis

## SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- PRIMARY KEY
- FOREIGN KEY
- UNIQUE
- Aggregate functions
- VIEW
- STORED PROCEDURE

## Tables

- Students
- Courses
- StudentMarks
- Skills
- StudentSkills

## Technology

- SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)

## How to Run

1. Open SQL Server Management Studio.
2. Open `Student_Profile_Project.sql`.
3. Connect to SQL Server.
4. Execute the complete SQL script.
5. The database and tables will be created automatically.
